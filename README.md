### 🤖 InterviewIQ
[GitHub](https://github.com/shubhra2604) &nbsp;|&nbsp; [Live Demo](https://interview-agent-x6kq.onrender.com/)

An **AI-powered interview preparation platform** that simulates realistic HR and technical interview rounds.

**Key Features:**

- 🧠 5 progressive GPT-generated questions per 7-minute mock interview session
- 📄 Resume upload and parsing to personalize interviews based on skills, projects, and role fit
- 🎯 Personalized interviews tailored to each candidate
- 📊 Performance evaluation across 4 metrics: correctness, communication, confidence, and final score
- 💳 Credit-based access via Razorpay (100 credits on signup, 50 credits per session)
- 🔐 Authentication using Firebase Auth & JWT

**Tech Stack:**  
`React` `Vite` `Redux` `Node.js` `Express` `MongoDB` `OpenRouter` `Firebase Auth` `JWT` `Razorpay` `Tailwind CSS`
